# Power-BI---Ecommerce-sales-Dashboard
Interactive Power BI dashboard for e-commerce sales analysis and business insights.

An interactive E-Commerce Sales Dashboard built using Microsoft Power BI to analyze sales, profit, quantity, and average order value. It provides insights into monthly profit trends, state-wise performance, payment methods, and product categories through interactive charts, KPI cards, and filters to support data-driven business decisions.

Project Overview
This report brings important e-commerce metrics into one place so users can review business performance and explore trends across time, geography, payment methods, and product sub-categories.

Dashboard Features
- Quarter filter: Select Qtr 1, Qtr 2, Qtr 3, or Qtr 4.
- State filter: Filter results by state.
- Profit by state: Compare profit across states.
- Profit by month: Identify monthly profit patterns, including positive and negative months.
- Quantity by payment mode: Compare COD, UPI, debit card, credit card, and EMI.
- Quantity by category/sub-category: Explore product quantity distribution.
- Profit by sub-category: Compare profitability across product sub-categories.
